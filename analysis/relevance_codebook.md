# 관련성 코드북 (초안)

대상: 브랜드 뉴스 정제 CSV (`data/processed/brand_news_filtered.csv`)
목적: 기사가 해당 브랜드를 **주제로 다루는지** 일관된 기준으로 판단한다.

## 입력 정보

- 제목, 요약(검색 API가 자른 짧은 본문), 브랜드명
- 요약은 전문이 아니므로, 판단이 애매하면 원문링크를 열어 확인한다.

## 등급

| 등급 | 코드 | 기준 |
|---|---|---|
| 주제 관련 | A | 제목 또는 요약 첫 문장에 브랜드가 있고, 그 브랜드의 상품·매장·실적·마케팅·이슈가 기사의 중심 내용이다. |
| 부차 언급 | B | 브랜드가 기사에 등장하지만 다른 주제(예: 업계 전반, 다른 기업 소개)의 예시나 비교 대상이다. |
| 무관 | C | 키워드는 있지만 브랜드와 관계가 없다. 같은 단어의 다른 의미이거나 배너·목록에만 나온다. |

## 판단 규칙

1. **제목 우선:** 제목에 브랜드가 없으면 기본적으로 A가 되기 어렵다. 단, 제목은 없어도 요약 첫 문장에서 주제가 명확하면 A로 본다.
2. **브랜드 개수:** 여러 SPA 브랜드를 나열한 시장 기사는 B로 본다. 그 브랜드만 집중해서 다루면 A다.
3. **같은 기사, 다른 브랜드:** 한 기사가 여러 브랜드 검색에 걸렸다면, 각 브랜드 기준으로 따로 등급을 매긴다.
4. **동음이의:** "탑텐"이 투표 항목, 프로그램 이름 등 다른 의미로 쓰이면 C로 본다.
5. **이벤트 기사:** 브랜드의 팝업, 세일, 협업이 주제면 A다. 해당 브랜드가 행사 장소의 입점 매장 중 하나로만 나오면 B다.
6. **판단 불가:** 요약만으로 판단하기 어려우면 "보류"로 두고 원문을 확인한 뒤 다시 정한다.

## 검증 절차

- 무작위 30건을 뽑아 두 명 이상이 독립적으로 라벨링한다. 혼자 한다면 하루 뒤 다시 라벨링해서 일치율을 본다.
- 일치율이 낮은 항목은 코드북 규칙을 고쳐서 다시 라벨링한다.
- 최종 규칙은 자동 규칙(제목 포함 여부 등)으로 옮기고, 샘플에서 정확도를 기록한다.

## 기록할 것

- 라벨러, 라벨링 날짜, 일치율, 규칙 변경 이력
- 제외한 건수와 기준 (`CLAUDE.md`의 규칙에 따라 기록한다)
